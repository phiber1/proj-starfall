STARFALL - a vertical space shooter for the TRS-80 MC-10
AN ABENE GAME

Needs: an MC-10 with the 8K internal RAM mod and an MCX32-SD, on a TV or
monitor that shows NTSC artifact color (or the VMC10 for Linux emulator,
run with --8k --mcx32sd).

Copy STARFALL.BIN and SFBOSS1.BIN to SFBOSS4.BIN to the SD card, then type

    RUNM"STARFALL"

Arrows (or W A S Z) move, SPACE fires; a PI-KEY10's joystick 1 works too.
If the color check screen shows blue instead of orange, press C.  The game
keeps its high score in STARFALL.HI on the card.

starfall.pdf has the rules.  Source: https://github.com/phiber1/proj-starfall
Public domain (Unlicense).
